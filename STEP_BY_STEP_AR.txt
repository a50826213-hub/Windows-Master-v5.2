WINDOWS MASTER 5.2 — START FROM ZERO
====================================

هذه هي النسخة الأصلية الجديدة بـ C# + XAML + WinUI 3، وليست Python.

الخطوة 1
-------
نزّل وثبّت Visual Studio 2026 من موقع Microsoft.
أثناء التثبيت، ضع علامة على:
WinUI application development

الخطوة 2
-------
تأكد أن .NET 10 SDK موجود:
افتح CMD واكتب:

dotnet --version

يجب أن يظهر رقم يبدأ بـ 10.

الخطوة 3
-------
فعّل Developer Mode:
Win + R
ثم:
ms-settings:developers

ثم فعّل Developer Mode.

الخطوة 4
-------
فك WindowsMaster_Native.zip في مجلد جديد، مثل:
C:\Users\AnasM\Documents\WindowsMaster_Native

الخطوة 5
-------
خذ ملف الشعار القديم عندك:
logo.ico
وانسخه إلى:
WindowsMaster_Native\Assets\logo.ico

الخطوة 6
-------
افتح PowerShell داخل مجلد WindowsMaster_Native.

الخطوة 7
-------
نفذ:

dotnet restore

الخطوة 8
-------
نفذ:

dotnet build -c Release -p:Platform=x64

الخطوة 9
-------
شغل البرنامج أثناء التطوير:

 dotnet run

أو افتح WindowsMaster.sln في Visual Studio واضغط F5.

الخطوة 10 — نشر النسخة النهائية
------------------------------
نفذ:

dotnet publish -c Release -r win-x64 --self-contained true

ابحث داخل:

bin\Release\net10.0-windows10.0.19041.0\win-x64\publish\

ستجد WindowsMaster.exe ومكونات النشر.

الخطوة 11 — Setup.exe
---------------------
بعد نجاح publish:
1) افتح Inno Setup Compiler.
2) افتح SETUP_INNO.iss.
3) Build > Compile.
4) النتيجة:
installer_output\Windows_Master_v5.2_Setup.exe

ما هو موجود في البرنامج
-----------------------
Home
Windows Settings
Control Panel
Repair
Maintenance
Performance
System Tools
Command Center

البحث العلوي يبحث في كل الأقسام.
الأدوات الحساسة لا تعمل مباشرة: يظهر تأكيد قبل التنفيذ.
الأدوات التي تحتاج Administrator تستخدم UAC وقت التنفيذ.
التطبيق نفسه لا يعمل دائمًا بصلاحيات Administrator.

هذا التصميم مقصود ليكون أقرب إلى تطبيق Settings حديث باستخدام WinUI 3، وليس نسخة Python ببطاقات CustomTkinter.
