\# 🛡️ WindowsMaster Native v5.2



برنامج WindowsMaster v5.2 هو أداة متكاملة لنظام التشغيل Windows بتصميم Fluent UI لتسهيل الوصول لإعدادات النظام وصيانته.



\## المميزات

\* قراءة حية لموارد الجهاز (CPU, RAM, GPU).

\* اختصارات لوحة التحكم وإعدادات النظام.

\* أدوات إصلاح وتنظيف ملفات النظام بضغطة زر.
